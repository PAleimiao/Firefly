## 四、iOS 用户特别说明

iOS 下音游比安卓麻烦，主要问题：**国区 App Store 很多音游没有**。

### 解决方案

**方案 A：注册外区 Apple ID（推荐）**
1. 去苹果官网注册一个新 Apple ID，地区选「美国」或「台湾」
2. 付款方式选「无」，地址随便填（网上搜「美国免税州地址生成器」）
3. 在 App Store 退出国区账号，登录外区账号
4. 搜游戏英文名直接下载

**方案 B：买现成外区账号（懒人）**
- 淘宝/闲鱼几块钱一个，记得要安全问题答案
- 风险：账号可能被找回，建议只用来下载，不绑定重要数据

**方案 C：自签 ipa（Phira 专用）**
- Phira 的 iOS 版在 GitHub 发布 ipa 文件
- 用 AltStore、Sideloadly 或 TrollStore 自签安装
- 每 7 天或 365 天（看工具）需要重新签一次
- **缺点**：无法使用资源包功能，这是系统限制

## 六、常见问题（FAQ）

**Q：为什么 Phigros 在应用商店搜不到？**
> 鸽游没上传统应用商店，只在 TapTap 独家发布。去 TapTap 搜，别在应用商店浪费时间。

**Q：Arcaea 国服和国际服有什么区别？**
> 数据不互通，曲包价格不同，国服更新稍慢。想跟国际排行榜同步就玩国际服，图方便就玩国服。

**Q：Phira 好游快爆版和 GitHub 版有什么区别？**
> 游戏本体一样，好游快爆版多了社区/攻略入口，GitHub 版是最新开源版本。推荐 GitHub 下，更新最快。

**Q：iOS 下 Phira 能换皮肤吗？**
> **不能**。ipa 自签安装的 Phira 无法使用资源包功能，这是 iOS 系统限制，不是 Phira 故意恶心你。

**Q：Google Play 下游戏需要梯子吗？**
> 需要。Google Play 本身需要梯子，部分游戏下载后游玩也需要加速器（比如 Arcaea 国际服）。

**Q：Steam 版 Muse Dash 和手机版互通吗？**
> 互通。绑定 TapTap 账号后，PC 和手机进度同步。
