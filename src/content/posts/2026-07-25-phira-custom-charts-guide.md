## 一、谱面哪里找？三大渠道

### 渠道1：Phira 官方谱面库（最正规）

登录 Phira 后，点「游玩」进入谱面库，里面有玩家上传的自制谱，按热度、最新、未上架分类。

![Phira谱面库导入界面](./images/phira-library-import.png)

但官方库审核比较严，很多谱面上架慢，或者因为版权/质量问题没过审。

### 渠道2：B站（谱面最多的地方）

**这是找谱的最佳渠道。**

在 B站搜索：
- `Phira 自制谱`
- `Phigros 自制谱`
- 你想打的**歌曲名 + 自制谱**

比如你想打《紅蓮華》，就搜「紅蓮華 Phira 自制谱」。

找到视频后，**重点看简介和评论区置顶**，谱师通常会把下载链接放在那里：

![Phira谱面文件下载](./images/phira-chart-download.png)

链接一般是蓝奏云、百度网盘、123云盘，点进去下载 `.pez` 或 `.zip` 文件就行。

> ⚠️ **注意**：有些谱面需要密码，密码也在简介或评论里，仔细找。

### 渠道3：QQ群 / Discord / 社区

加入 Phira 交流群，群里经常有人分享新谱、资源包、活动信息。

## 二、谱面文件长啥样？

下载下来的谱面通常是这两种格式：

| 格式 | 说明 | 怎么处理 |
|------|------|----------|
| `.pez` | Phira 专用谱面包 | 直接导入，不用解压 |
| `.zip` | 压缩包 | 先解压，看里面有没有 `.json` + 音频文件 |

如果下载的是 `.zip`，解压后应该能看到：
- `chart.json` 或 `chart_*.json`（谱面数据）
- `song.mp3` 或 `song.ogg`（歌曲音频）
- `illustration.png` 或 `bg.jpg`（曲绘/背景）

## 三、如何导入 Phira？

### 方法A：直接导入 .pez 文件（最简单）

1. 打开 Phira，点右上角 **「导入」**
2. 选择你下载的 `.pez` 文件
3. 等几秒，谱面就出现在「本地」列表里了

![Phira资源包界面](./images/phira-resource-pack.png)

### 方法B：手动放文件（适合 .zip 解压后的）

如果 `.pez` 导入失败，或者你下载的是散文件，可以手动放：

1. 打开手机文件管理器
2. 找到 Phira 的数据目录（不同手机路径不同，常见路径）：
   - `/Android/data/com.phira/files/charts/`
   - 或者 `/Phira/charts/`
3. 把谱面文件夹（包含 .json + 音频 + 曲绘）复制进去
4. 重启 Phira，在「本地」里应该能看到

> 如果找不到路径，在 Phira 设置里看看「谱面存储路径」配置。

### 方法C：通过资源包导入（按键皮肤 + 谱面打包）

有些大佬会把谱面和按键皮肤打包成资源包一起发：

1. 下载资源包（`.zip` 格式）
2. Phira 里点「资源包」→「+」号
3. 选择下载的 `.zip` 文件
4. 导入成功后，谱面和皮肤都有了

## 四、资源包导入（按键皮肤）

Phira 支持自定义按键皮肤，让打击感更爽。

### 哪里找资源包？

- B站搜「Phira 按键皮肤」「Phira 资源包」
- 233乐园、虫虫助手等游戏社区
- Phira 交流群

热门皮肤：樱花、百合、极光、幻影、星光粉、霓虹……

### 怎么导入？

1. Phira 主界面点 **「资源包」**
2. 点左下角 **「+」号**
3. 选择下载好的资源包 `.zip` 文件
4. 导入成功后，在列表里启用

![Phira资源包界面](./images/phira-resource-pack.png)

> 资源包和谱面是分开的，导入资源包不会自动导入谱面，除非打包在一起。

## 五、想自己写谱？RePhiEdit 了解一下

看别人打的谱很爽，但**自己写谱更爽**。

Phigros/Phira 的自制谱编辑器叫 **Re:PhiEdit**（简称 RPE），是目前社区最主流的制谱工具。它输出的格式叫 **RPEJSON**，被 Phira、PhiZone、Phigrim 等社区音游通用支持。citeweb_search:77#0

![RePhiEdit Logo](./images/rephiedit-logo.png)

### 5.1 下载 RePhiEdit

- GitHub 仓库：`https://github.com/RePhiEdit/RePhiEdit`
- 审核 QQ 群：794777846（群里有大佬指导，但别当伸手党）

> ⚠️ **门槛警告**：RPE 官方建议能**稳定 V 评 90% 以上 IN15 级曲**再尝试写谱。  
> 但只是写着玩的话，谁都能写，只是质量可能……你懂的。

### 5.2 RPE 写谱基本流程

1. **准备音频**：把你想写的歌转成 `.ogg` 格式（Phira 对 `.ogg` 支持最好，`.wav` 文件太大会导致上传失败）citeweb_search:77#9
2. **新建项目**：打开 RPE，新建谱面，导入音频，软件会自动检测 BPM
3. **写配置**：设置谱面信息（曲名、谱师、难度、偏移量）
4. **放音符**：在时间轴上放 Tap、Hold、Drag、Flick 四种音符
5. **调演出**：判定线移动、旋转、透明度变化、速度事件（这是 Phigros 谱面的灵魂）
6. **测试**：按 `T` 键预览，或者按 `Y` 键实时预览（需要开启实时预览选项）citeweb_search:77#2
7. **纠错**：看右上角的横线，绿色=没问题，红色=有 Error 必须改

> **RPE 坐标系**：屏幕范围是 `[-675, 675] x [-450, 450]`，中心点是 `(0, 0)`。citeweb_search:77#2  
> 音符的 `positionX` 范围是 `-1.0` 到 `1.0`，对应屏幕左右边缘。

### 5.3 音符类型说明

RPE 里有四种基础音符，跟 Phigros 官谱一致：

| 类型 | RPE 里叫法 | 玩家视角 | 写法要点 |
|------|-----------|---------|---------|
| **Tap** | Single | 单点 | 最基础的音符，点一下 |
| **Hold** | Hold | 长按 | 有持续时间（holdTime），手指按住别松 |
| **Drag** | Drag | 滑动 | 手指划过即可，不用点击 |
| **Flick** | Flick | 滑动 | 需要滑动方向，通常配合演出效果 |

> 双押（两个音符同时出现）在 RPE 里通过 `_mh`（multi-hold）贴图区分，但数据上就是两个音符时间相同。

### 5.4 判定线与演出事件

Phigros/Phira 谱面最大的特色是**判定线会动**。

RPE 里每条判定线可以绑定以下事件：

- **移动事件**（Move）：判定线在屏幕上平移
- **旋转事件**（Rotate）：判定线绕中心旋转
- **透明度事件**（Disappear）：判定线渐隐渐现
- **速度事件**（Speed）：音符下落速度变化

> **关键概念**：父线（Parent Line）。子线的坐标系会以父线的位置为原点。这意味着你可以让一条线绕着另一条线转，做出复杂的轨道效果。citeweb_search:77#2

### 5.5 导出 PEZ 文件（Phira 专用格式）

RPE 写完后，需要导出成 **PEZ** 格式才能导入 Phira。

**PEZ 的本质就是 ZIP 压缩包**，里面必须包含这些文件（全部放在根目录，不能套文件夹）：citeweb_search:77#4

```
你的谱面.pez  （ZIP格式，改后缀）
  ├── chart.json        # 谱面数据（RPEJSON格式）
  ├── info.txt          # 谱面信息配置文件
  ├── 歌曲.ogg          # 音频文件（必须是ogg）
  └── illustration.png  # 曲绘/封面图（可选但建议有）
```

**info.txt 写法**（简单键值对，一行一个）：citeweb_search:77#4

```
title: 你的歌曲名
artist: 曲师名
designer: 你的谱师名
difficulty: 15
level: 15
audio: 歌曲.ogg
```

**导出步骤：**

1. RPE 里点「文件」→「导出」→ 选择导出路径
2. 把导出的文件和音频、曲绘放一起
3. 全选，压缩成 `.zip`
4. **改后缀为 `.pez`**
5. 导入 Phira，测试游玩

> ⚠️ **注意**：如果音频是 `.wav` 格式，务必转成 `.ogg`（不能直改后缀，要用格式工厂或在线转换转码），否则 Phira 上传时可能报 `413 length limit exceeded` 错误。citeweb_search:77#9

### 5.6 进阶：着色器与异象（extra.json）

Phira 支持通过 `extra.json` 文件实现**谱面异象**（BGA、着色器特效），让谱面有官方 IN/AT 那种炫酷效果。citeweb_search:77#0

但这属于高阶内容，需要懂 GLSL 着色器编程。萌新先别碰，先把基础谱面写明白再说。

### 5.7 写谱避坑指南

- **别一上来就写高难度**：先从 EZ/Hard 练手，熟悉音符摆放和演出逻辑
- **常看纠错**：RPE 右上角有 Error/Warning/Caution 提示，Error 必须改，Warning 仔细看citeweb_search:77#2
- **BPM 要对准**：音频导入后务必检查 BPM 是否准确，差一点都不行
- **多保存**：RPE 有自动保存，但手动 `Ctrl+S` 更保险
- **别塞爆**：观赏谱不是瞎塞，配置是检验谱面的根本标准citeweb_search:77#2

## 六、常见问题

**Q：导入后谱面不显示？**
> 检查文件格式对不对，`.pez` 直接导，`.zip` 要解压或改后缀。也可能是路径放错了。

**Q：谱面有声音没画面/有画面没声音？**
> 音频文件格式不对，转成 `.mp3` 或 `.ogg` 试试。或者谱面 JSON 里的文件路径配置错了。

**Q：B站下载的谱面链接失效了？**
> 蓝奏云链接容易失效，试试在评论区翻一翻，或者去 QQ 群里问。也可以直接私信谱师要。

**Q：自己写的谱怎么分享给朋友？**
> 打包成 `.pez`，丢蓝奏云/百度网盘，把链接发给朋友。或者上传到 Phira 谱面库（需要审核）。

**Q：Phira 和 Phigros 的谱面通用吗？**
> 不完全通用。Phira 基于 Phigros 格式，但有一些扩展。Phigros 官谱导入 Phira 需要转换工具。

## 八、自制资源包（按键皮肤）

总有人问「资源包怎么自己做」「我想换个按键颜色咋弄」。

行，既然那帮**连百度都不会用的**都要自己做，这篇直接教。以下内容来自 Phira 官方文档和社区 Wiki，**照着做不会错**。citeweb_search:77#12

### 8.1 资源包文件结构（官方规范）

Phira 资源包是**单个 ZIP 压缩文件**，里面必须包含配置文件 `info.yml` 和各种资源文件。

**必须存在的文件**（少了哪个都会报错）：

| 文件名 | 说明 |
|--------|------|
| `info.yml` | 配置文件（YAML格式） |
| `click.png` | Tap 音符单押皮肤 |
| `click_mh.png` | Tap 音符双押皮肤（mh = multi-hold） |
| `drag.png` | Drag 音符单押皮肤 |
| `drag_mh.png` | Drag 音符双押皮肤 |
| `flick.png` | Flick 音符单押皮肤 |
| `flick_mh.png` | Flick 音符双押皮肤 |
| `hold.png` | Hold 音符单押皮肤 |
| `hold_mh.png` | Hold 音符双押皮肤 |
| `hit_fx.png` | 打击特效图片 |

**可选文件**（没有就用默认）：

| 文件名 | 说明 |
|--------|------|
| `click.ogg` | Tap 打击音效 |
| `drag.ogg` | Drag 打击音效 |
| `flick.ogg` | Flick 打击音效 |
| `hold.ogg` | Hold 打击音效 |
| `ending.ogg` | 结算界面背景音乐 |
| `sound/` 文件夹 | 音效统一放这里也行 |

> ⚠️ **音效格式警告**：音效文件必须是 `.ogg` 格式，且**采样率必须为 44100Hz**。如果采样率不对，在渲染时（prpr-render）会导致崩溃。citeweb_search:77#12

### 8.2 info.yml 配置文件写法

`info.yml` 是资源包的"身份证"，用 **YAML 格式**（不是 JSON！）。

**必填字段**（一个都不能少）：citeweb_search:77#12

```yaml
name: 你的资源包名字
author: "你的名字"
hitFx: [5, 6]           # 打击特效的横向和纵向分割数
holdAtlas: [50, 50]     # 单押 Hold 的宽高比参考值
holdAtlasMH: [50, 110]  # 双押 Hold 的宽高比参考值
```

字段详解：

- **`name`**：资源包显示名称，导入后在 Phira 里看到的名字
- **`author`**：作者名，建议加引号防止特殊字符出错
- **`hitFx: [5, 6]`**：打击特效图片 `hit_fx.png` 会被切成 5x6 的网格，用于随机播放不同角度的特效。数字越大特效越细腻，但建议 `[5, 6]` 或 `[4, 4]` 就行
- **`holdAtlas: [50, 50]`**：单押 Hold 音符的宽高比参考。Hold 的高度由 `Floor Position × (标准宽高比 / 实际宽高比)` 决定，标准宽高比是 **3:2**citeweb_search:77#12
- **`holdAtlasMH: [50, 110]`**：双押 Hold 的宽高比参考。双押贴图通常比单押宽，所以第二个数字更大

**可选字段**：

```yaml
useAudio: ogg   # 指定音频格式，可选 ogg 或 wav（推荐 ogg）
```

> 老版本 WebKit 不支持 OGG，所以奇谱发生器支持用 `useAudio` 字段指定格式。但 Phira 本身对 OGG 支持很好，直接写 `ogg` 就行。citeweb_search:77#12

### 8.3 图片尺寸与绘制规范

**核心原则**：单押和双押必须在**同一个分辨率画布**下绘制，否则大小会错乱。citeweb_search:77#12

**具体缩放规则**：

- **单押非 Hold 音符**（Tap/Drag/Flick）：等宽高比缩放到以「播放器宽度参数」为宽
- **双押非 Hold 音符**：等宽高比缩放到以 `播放器宽度参数 × (双押贴图宽度 / 单押贴图宽度)` 为宽
- **Hold 音符**：宽度要求同上，高度由 `Floor Position × (标准宽高比 / 实际宽高比)` 决定

**建议尺寸**（按官方默认资源包比例）：

| 文件 | 建议画布尺寸 | 格式 |
|------|-------------|------|
| click/drag/flick | 200×200 或 256×256 | PNG（透明背景） |
| click_mh/drag_mh/flick_mh | 同上画布，但图形更宽 | PNG |
| hold | 200×300（3:2比例） | PNG |
| hold_mh | 200×300（3:2比例） | PNG |
| hit_fx | 256×256 或更大 | PNG |

**绘制建议**：
- 用 **透明背景 PNG**，白边会很难看
- 单押和双押在同一个 PSD 里画，保证比例一致
- 颜色别太暗，Phira 背景偏深，暗色按键会看不清
- 双押（`_mh`）可以画成两个音符并排，或者更宽的图形

### 8.4 音效制作与格式要求

**硬性要求**：
- 格式：`.ogg`（Vorbis编码）
- 采样率：**44100Hz**（必须！否则渲染崩溃）citeweb_search:77#12
- 声道：单声道或立体声都行

**获取方式**：
1. **从其他资源包提取**：下载别人的资源包，解压后把 `sound/` 里的 `.ogg` 复制出来改
2. **网上下载**：搜「音游打击音效」「SE 音效包」
3. **自己录**：用手机录按键声、敲击声，然后用 Audacity 剪辑导出

**格式转换**（如果下载的是 MP3/WAV）：
- 电脑：用 **Audacity**（免费）→ 导入 → 导出为 OGG → 采样率选 44100Hz
- 手机：用 **格式工厂 App** 或在线转换网站
- 在线转换：`https://convertio.co/zh/`（上传 → 选 OGG → 下载）

### 8.5 打包与导入

所有文件准备好后：

1. 把 `info.yml` + 所有 `.png` + 所有 `.ogg` 放到一个文件夹里
2. **全选 → 压缩成 `.zip`**
3. 文件名随便起，比如 `我的皮肤.zip`

导入 Phira：

**「资源包」→ 左下角「+」号 → 选择你的 `.zip` → 导入成功**

> 注意：资源包是 `.zip`，不是 `.pez`。`.pez` 是谱面包的格式，别搞混了。

### 8.6 测试 & 常见问题

导入后打几首歌测试，常见问题：

| 问题 | 原因 | 解决 |
|------|------|------|
| 按键显示异常/大小不对 | 单押双押分辨率不一致 | 确保 `_mh` 和原版在同一个画布尺寸下绘制 |
| 音效没声音 | 采样率不是 44100Hz | 用 Audacity 重新导出，强制 44100Hz |
| 导入失败/闪退 | `info.yml` 格式错误或缺少必填字段 | 检查 YAML 缩进，确保 name/author/hitFx/holdAtlas/holdAtlasMH 都有 |
| Hold 显示成方块 | holdAtlas 比例不对 | 按 `[50, 50]` 和 `[50, 110]` 调整 |
| 打击特效不显示 | hit_fx.png 尺寸不对 | 确保能被 hitFx 参数整除（比如 5×6=30 格） |

### 8.7 分享你的资源包

做好了想分享？

1. 把 `.zip` 丢到 **蓝奏云**（不限速、不用登录）或 **123云盘**
2. 写清楚「适配 Phira v0.8.x」，注明作者和更新日期
3. 发到 B站视频简介、QQ群、Phira 社区

> 建议附上一张预览图（游戏内截图），别人一眼就能看出风格。

## 结语

Phira 最大的魅力就是**社区创作**。官方谱打腻了？没关系，社区里有成千上万张自制谱等着你，从 EZ 到 AT 到 SP，从正常谱到粪谱到观赏谱，应有尽有。

而且**你自己也可以成为谱师**。也许一开始写的谱很菜，但谁不是从粪谱师成长起来的呢？

> 最后，尊重谱师劳动成果，下载了谱面记得给视频三连，有条件的话支持一下原创。

如果你看完这篇还是找不到谱/导不进去/写不出来，**欢迎回来问我**，或者去 Phira 群里抓个谱师问问。

*P.S. 本文基于 Phira v0.8.x，如果后续版本导入方式有变，大体流程应该差不多。*
